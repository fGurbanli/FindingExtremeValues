# Array Statistics Analyzer (C)

A simple C program that demonstrates array processing using functions.

## Features

* Reads 6 integer values from the user
* Stores values in an array
* Prints all array elements
* Finds the maximum value
* Finds the minimum value
* Counts how many times the maximum value occurs
* Counts how many times the minimum value occurs
* Displays the positions of the maximum value
* Displays the positions of the minimum value

## Concepts Practiced

* Arrays
* Functions
* Function parameters
* Array traversal
* Conditional statements (`if`, `else if`)
* Loops (`for`)
* User input with `scanf`
* Returning values from functions
* Counting occurrences in an array
* Finding element positions

## Example

Input:
5 5 10 10 3 3

Output:
5 5 10 10 3 3

Maximum value is: 10
Maximum value occurred 2 times
Maximum value positions: 3 4

Minimum value is: 3
Minimum value occurred 2 times
Minimum value positions: 5 6

## Functions

### `ReadIntArray()`

Reads integer values from the user and stores them in an array.

### `PrintArray()`

Prints all elements of the array.

### `FindMaximumValue()`

* Finds the largest value in the array
* Counts how many times it appears
* Prints its positions
* Returns the maximum value

### `FindMinimumValue()`

* Finds the smallest value in the array
* Counts how many times it appears
* Prints its positions
* Returns the minimum value
