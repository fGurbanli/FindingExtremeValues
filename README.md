# Array Min-Max Finder (C)

A simple C program that demonstrates basic array operations.

## Features

* Reads 6 integer values from the user
* Stores the values in an array
* Prints all array elements
* Finds and displays the maximum value
* Finds and displays the minimum value

## Concepts Practiced

* Arrays
* Functions
* Function parameters
* Loops (`for`)
* User input with `scanf`
* Returning values from functions
* Array traversal

## Example

Input:
1 7 3 9 2 5

Output:
1 7 3 9 2 5
Maximum value is: 9
Minimum value is: 1

## Functions

### `ReadIntArray()`

Reads integer values from the user and stores them in an array.

### `PrintArray()`

Prints all elements of the array.

### `FindMaximumValue()`

Finds and returns the largest value in the array.

### `FindMinimumValue()`

Finds and returns the smallest value in the array.
